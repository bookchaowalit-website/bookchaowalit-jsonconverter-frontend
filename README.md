# JSON Converter

Format JSON, minify it, or convert to simple YAML — all client-side.

## Features
- Pretty-print with 2-space indent
- Minify
- JSON → YAML (common object/array shapes)
- YAML → JSON for simple documents

## Limitations
- YAML support is intentionally simple (no anchors/tags)
- Not a full jq replacement

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
