# bookchaowalit-jsonconverter-frontend — Product brief

**Slug:** `bookchaowalit-website/bookchaowalit-jsonconverter-frontend`
**Status:** local developer utility / portfolio boundary

## Purpose

JSON Converter gives developers a quick browser-only workspace to pretty-print
or minify JSON and move simple data between JSON and YAML.

## Audience and scene

Developers cleaning payloads, inspecting config, or preparing a small snippet
to paste elsewhere. The useful path is visible immediately: edit input, choose
an operation, inspect output, and copy it.

## Constraints

- Fully client-side; no API keys, account, or server-side storage.
- YAML support is intentionally simple and is not a jq replacement.
- Preserve the existing pretty JSON, minify, JSON → YAML, and YAML → JSON paths.
